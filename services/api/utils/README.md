# API Utils Directory

This directory contains utility functions for API operations.

## Structure

```
utils/
├── api.utils.ts         # Common API utility functions
├── error.utils.ts       # Error handling utilities
├── storage.utils.ts     # Storage management utilities
├── validation.utils.ts  # Request validation utilities
└── transform.utils.ts   # Data transformation utilities
```

## Purpose

- **api.utils.ts**: Common functions for API requests, response handling
- **error.utils.ts**: Error parsing, formatting, and handling
- **storage.utils.ts**: AsyncStorage wrapper functions
- **validation.utils.ts**: Input validation before API calls
- **transform.utils.ts**: Data transformation between API and app formats
